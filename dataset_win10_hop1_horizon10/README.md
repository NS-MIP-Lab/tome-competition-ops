作成日: 2026-08-29

## まず結論

**学習に使うのは `train_window.csv` の1つだけです。** 残りは元データや確認のための表です。

読み込みは次のとおり。すべて UTF-8（BOM 付き）、列名は日本語です。

```python
import pandas as pd
df = pd.read_csv("train_window.csv", encoding="utf-8-sig")
```

### ラベル

### マスク

| 列 | 0 の行数 | 0 になる条件 |
|---|---|---|
| `介入ラベル有効` | 0 | 検証用セッション（今回は無し） |

## 正規化について

**追加の標準化は不要です。** 特徴量59列は次の処理を済ませてあります。

1. 非負の列に `log1p` を掛ける（帯域パワーや件数は右に強く裾を引くため）
2. **被験者ごとに**、課題の最初の3分を基準に平均と標準偏差で z 化

`標準化の基準` 列に、どの区間を基準にしたかが入っています。基準区間で値が動かない列（`心拍_pNN50` が5セッション）はセッション全体の広がりで割っています。

**交差検証との関係。** 正規化は被験者ごとに閉じているため、被験者で分割する限り、分割をまたいだ情報の漏れは起きません。

**未来を使っていません。** 基準は課題の最初の3分だけなので、実運用でも同じことができます。

脳波は相対パワー（帯域 ÷ そのチャネルの4帯域合計）と総パワーが入っています。絶対パワー16列は外してあります（`features_window.csv` には残っています）。

## 使うときの注意

### 1. 分割は必ず `被験者ID` で

```python
from sklearn.model_selection import GroupKFold
GroupKFold(n_splits=4).split(X, y, groups=df["被験者ID"])
```

**窓は9秒ぶん重なっています。** 無作為に分割すると、ほぼ同じデータが訓練とテストの両方に入り、性能が実際より高く出ます。同じ被験者が2〜3セッション持つので、セッション単位ではなく被験者単位で分けてください。

### 2. 正例は191行だが、実際の押下は20回

押下1回から正例の窓が10行できます（先読み10秒 × 1秒ずらし）。**この10行はほぼ同じデータです。**

```
正例 191 行 / 全 24,049 行（0.79%）
実際の押下 20 回
```

論文や報告で標本数を書くときは、行数ではなく**押下回数**で数えてください。被験者ごとに分けると、検証側の押下は1〜9回になります。**S06 を検証にした回は押下1回**なので、その分割の数字はほぼ意味を持ちません。各分割の値を平均せずに並べて出すことを勧めます。

### 3. S06/pE のブロック別特徴量は信用しない

視線の座標変換の当てはまり（`surface_fit.csv` の `文字範囲一致率_コード帯`）がセッションで違います。

| セッション | 一致率 |
|---|---|
| S03/pE | 76.3% |
| S04/pE | 72.8% |
| S04/pD | 69.4% |
| S05/pE | 61.3% |
| S03/pD | 55.8% |
| S04/pC | 54.0% |
| S06/pD | 52.8% |
| S05/pD | 51.6% |
| **S06/pE** | **43.8%** |

50% を大きく下回る S06/pE では、`視線_B1率`〜`視線_B6率` がどのブロックを見ていたかを正しく表していません。この2724行を除くか、ブロック別の列を外してください。

`視線_コード縦移動量毎秒` `視線_コード縦分散` `視線_往復回数毎秒` はブロック境界を使わないので、当てはまりが低くても影響を受けません。

### 4. ブロック別の列は問題に依存します

`視線_B1率`〜`B6率` は「コードのどの位置を見たか」です。pD と pE はブロック構成をそろえてあり、どちらも B5 が「主処理の入れ子ループ」を指します。**この2問の間でのみ同じ意味を持ちます。** 未知のコードに対する汎化の根拠にはなりません。

### 5. 課題の進行度は入っていません

`設問` と `窓開始秒` は特徴量から外してあります。押下は課題の終盤と特定の設問に偏るため、これを入れるとモデルが生体情報を見ずに「終盤なら押される」と学習できてしまうためです。必要なら `--progress-columns` を付けて作り直せます。

## 作り直したいとき

```bash
python preprocess/build_dataset.py \
  --task-data <本実験のフォルダ> \
  --out dataset_win10_hop1_horizon10 \
  --no-gaze-samples
```

このディレクトリは**既定の設定**（窓10秒・1秒ずらし・先読み10秒・脳波は相対パワー・最初の3分で標準化）で作ったものです。設定を変えるときは別のディレクトリ名にしてください。

```bash
--window 10 --hop 1 --horizon 10          窓の作り方
--standardize {baseline,session,none}     正規化の基準
--baseline-min 3.0
--eeg-columns {relative,absolute,both}    脳波の列
--progress-columns                        進行度も入れる
```

`dataset_*/` は `.gitignore` で無視されます。このディレクトリだけ例外として追跡しています。

前処理の詳細は [`../preprocess/README.md`](../preprocess/README.md) にあります。
